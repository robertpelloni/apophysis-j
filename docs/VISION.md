# Vision

Apophysis-j is a cross-platform Java port of the legendary Windows fractal flame editor, Apophysis. It is targeted at running smoothly on Mac, Linux, and Windows using modern Java environments.

## Long-term goal
The goal is to maintain feature parity with the original Apophysis, integrate with `flam3` renderers, and provide an extensible, plugin-friendly architecture for fractal artists globally.
